# java-quiz-application


## Introduction

This project is a simple Quiz Application made using Java. The application allows a user to enter their name and attempt a quiz containing multiple-choice questions.

Each question has four options and a time limit of 15 seconds. The application checks the selected answer, calculates the score and displays the final result after the quiz is completed.

The main purpose of this project is to understand and apply Java concepts such as classes and objects, encapsulation, ArrayList, file handling, exception handling, multithreading and Java Swing.

---

## Problem Statement

Taking a quiz manually can take time when questions, answers and scores have to be managed separately.

This project provides a simple computer-based quiz where questions are displayed through a graphical interface, answers are checked automatically and the final score is calculated without manual calculation.

---

## Objectives

The main objectives of this project are:

- To create a simple quiz application using Java.
- To provide a graphical interface for the user.
- To display multiple-choice questions and options.
- To add a timer for each question.
- To calculate the score automatically.
- To store quiz results for future reference.
- To practice Object-Oriented Programming concepts in Java.
- To understand how different Java classes can work together in one application.

---

## Features

- Enter player name before starting the quiz.
- Multiple-choice questions with four options.
- 15-second timer for every question.
- Automatic movement to the next question when time is over.
- Automatic checking of answers.
- Automatic score calculation.
- Percentage calculation.
- Result screen after completing the quiz.
- Score history stored in a text file.
- Option to view previous scores.
- Restart quiz option.
- Exit option.
- Basic input validation and error handling.
