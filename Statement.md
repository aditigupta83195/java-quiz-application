# Project Statement

## Project Title

Java Quiz Application

---

## Problem Statement

Students often use quizzes to test their knowledge, but conducting and checking quizzes manually can take time.

The aim of this project is to develop a simple Java-based quiz application where users can answer multiple-choice questions through a graphical interface. The application checks the answers automatically, keeps track of the score and displays the final result.

A timer is also included for each question to make the quiz more interactive.

---

## Scope of the Project

The project focuses on creating a basic desktop quiz application using Java.

The application allows a user to:

- Enter their name.
- Start a quiz.
- Answer multiple-choice questions.
- Get a limited amount of time for each question.
- Move to the next question after answering.
- Automatically move to the next question when the time runs out.
- View their final score and percentage.
- View saved quiz score history.
- Restart the quiz.
- Exit the application.

The current version is designed as a simple standalone application and does not require an internet connection or an external database.

---

## Target Users

The main users of this application are:

- Students who want to practice Java-related questions.
- Beginners who want to test their basic Java knowledge.
- Teachers or students who want a simple quiz system for educational purposes.

---

## High-Level Features

### 1. Player Name

The application asks the user to enter their name before starting the quiz.

### 2. Multiple-Choice Questions

Each question contains four options. The user can select one option as their answer.

### 3. Timer

Each question has a 15-second time limit. If the user does not answer within the given time, the application automatically moves to the next question.

### 4. Answer Checking

The selected answer is compared with the correct answer stored in the application.

### 5. Score Calculation

The score is updated whenever the user selects a correct answer.

### 6. Result Display

After completing all the questions, the application displays the player's name, score and percentage.

### 7. Score History

The application saves quiz results in a text file and allows the user to view previously saved results.

### 8. Restart Quiz

The user can restart the quiz after viewing the result.

### 9. Input Validation

The application checks whether the player has entered a name and whether an answer has been selected before moving to the next question.

## Expected Outcome

The expected outcome of this project is a working Java desktop application that can conduct a timed multiple-choice quiz, check answers, calculate the score and store quiz results.

The project also helps in understanding how different Java programming concepts can be combined to create a complete application.

---

## Project Limitations

The current version has some limitations:

- Questions are stored directly in the Java program.
- The application uses a text file instead of a database.
- There is no user login system.
- The application is designed for local desktop use.
- The current question set is limited.

These limitations can be addressed in future versions of the project.
